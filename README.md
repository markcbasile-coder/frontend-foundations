# Frontend Foundations

A structured collection of core web development projects focused on semantic markup, modern layout techniques, and responsive styling without relying on frameworks or application logic.

---

## 🚀 Overview

**Frontend Foundations** serves as a hands-on repository for mastering foundational web technologies. Each folder inside this repository represents an independent project designed to build proficiency in HTML5 architecture, CSS layouts (Flexbox & Grid), accessibility, and responsive UI design principles.

---

## 🛠️ Key Focus Areas

- **HTML5:** Semantic document architecture, web accessibility (a11y) standards, forms, media elements, and structural best practices.
- **CSS3 Layouts & Styling:** 
  - Flexbox and CSS Grid layout systems
  - Mobile-first responsive design and media queries
  - CSS custom properties (variables) and modern sizing units (`rem`, `em`, `vh`, `vw`)
  - Box model mechanics, positioning context, and specificity management
- **UI Design Principles:** Typography scale, color contrast standards, cross-browser styling consistency, and clean code formatting.

---
